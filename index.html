Pertanyaan Umum

Apakah ada biaya bulanan atau sewa hosting?
Untuk Paket Express, tidak ada biaya bulanan sama sekali untuk server/hosting. Kami menggunakan teknologi static modern dan GitHub Pages sehingga web Anda online gratis selamanya.
Bagaimana jika saya tidak mengerti coding?
Website ini memang dirancang khusus untuk orang awam. Anda tidak perlu menyentuh kode sama sekali. Untuk mengubah harga produk, menambah stok, atau mengubah teks, Anda cukup mengetiknya di Google Sheets dari HP Anda.
Berapa lama proses pembuatan website?
Untuk Paket Express, website bisa langsung jadi dan online dalam waktu 1x24 jam setelah Anda mengirimkan data lengkap. Untuk Paket Custom, proses memakan waktu 3-5 hari kerja.
Apakah saya bisa menggunakan domain sendiri (.com / .id)?
Sangat bisa! Namun, harga paket belum termasuk biaya pembelian domain. Kami bisa membantu Anda menyambungkan website ini ke domain .com atau .id milik Anda sendiri.
Bagaimana cara mengelola datanya dari HP?
Kami menyediakan Panel Admin khusus yang sangat ringan dan mudah digunakan dari HP. Anda cukup login dengan link kunci Anda, lalu Anda bisa mengedit nama produk, harga, stok, hingga banner promo secara instan tanpa perlu menyentuh kode sama sekali.
